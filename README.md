## 1. Overview

This repository contains the implementation of our sim-to-real 3D LiDAR perception and synthetic scene generation framework for the **UCF UrbanTwin Sim2Real LiDAR Challenge (LUMPI Track)**. Our method trains a 3D object detector **exclusively on synthetic LiDAR point clouds** for zero-shot evaluation on held-out real-world roadside LiDAR scans from the LUMPI intersection dataset.

The framework consists of three core stages:
1. **Unsupervised Spatio-Temporal Domain Adaptation & Synthetic Scene Generation:**
   - **Temporal-Persistence Static Background Modeling:** Aggregates multi-frame voxel occupancy across unlabeled non-forbidden point clouds to separate stationary intersection infrastructure from moving traffic without accessing any ground-truth annotations (`ROC-AUC = 0.929`).
   - **Distributional Realism & Training Scene Composition:** Combines an analytic multi-beam ground ring model, static intersection environment structures, and range-attenuated foreground object clusters to synthesize both the 50 submitted realism point clouds (`0001.bin`–`0050.bin`) and a 12,000-frame synthetic training corpus.
2. **Multi-Scale Pillar-Based Sim-Only 3D Detector:**
   - Employs a customized PointPillars / SECOND single-stage 3D detection architecture with a full-resolution ($1\times$ BEV) multi-scale feature aggregation neck, bimodal multi-scale oriented anchors, and size-adaptive 2D Gaussian soft center target assignment.
3. **Label-Free Test-Time Geometric Post-Processing:**
   - Applies class-selective multi-view transformation consensus, size-prior cross-category hypothesis calibration, and in-box test point-cloud physical support calibration with bounded centroid/orientation refinement.

## 2. Rule Compliance and Real-Data Usage

- **Strict Exclusion of Forbidden Frames:** All 100 frame IDs listed in `forbidden_frames.txt` (comprising the 50 held-out detection test frames and 50 held-out realism reference frames) are programmatically excluded prior to any data processing, statistical profiling, or local validation (`0 / 100` overlap).
- **100% Sim-Only Detector Training:** The 3D detector is trained from scratch exclusively on synthetic point clouds generated by our pipeline. No real ground-truth labels, no real 3D bounding boxes, and no real-box-cropped points are used during training.
- **Permissible Non-Forbidden Real-Data Usage:** Following the official challenge guidelines, the remaining non-forbidden public LUMPI training frames are used strictly for:
  1. Unsupervised temporal-persistence background and cluster profiling on unlabeled point clouds;
  2. Estimating aggregate scene-level class dimension and spatial placement priors;
  3. Local model selection and two-fold post-processing cross-validation on a fixed 133-frame non-forbidden holdout split.

## 5. Reproducing the Final Submission (`lumpi-simonly-pp-sbg3-v3`)

### Step 1: Unsupervised Background & Foreground Profiling (Non-Forbidden Frames Only)
Extract the unsupervised temporal-persistence static background pool and unlabeled foreground cluster bank after programmatically filtering out all 100 frame IDs in `forbidden_frames.txt`:
```bash
python build_static_bg.py
python build_objbank.py
```

### Step 2: Synthetic Realism Point Clouds & Sim-Only Training Corpus Generation
Generate the 50 submitted synthetic point clouds (`synthetic/0001.bin`–`0050.bin`, 50,000 points per frame in little-endian `float32` `(x, y, z)` format) and the 12,000-frame synthetic training set:
```bash
python gen_sub_frames.py
python build_trainset.py
```

### Step 3: Sim-Only Multi-Scale Pillar Detector Training
Train the multi-scale pillar-based 3D detector from scratch exclusively on the generated synthetic training corpus:
```bash
python train_pp.py
```

### Step 4: Test-Time Multi-View Inference, Geometric Calibration & Packaging
Run multi-view test-time inference, apply size-prior cross-category calibration and in-box point-cloud support refinement on the 50 held-out test point clouds, and verify the resulting submission archive:
```bash
python pred_passes.py
python tta_fuse.py
python refine_zip.py
python check_submission.py
```

The final submission package contains:
- `synthetic/0001.bin` – `synthetic/0050.bin` (50 synthetic LiDAR scenes)
- `predictions.json` (3D bounding box predictions across the 50 held-out test frames)
- `declaration.pdf` (signed honor declaration)
